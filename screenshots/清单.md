# 实验一 · 截图清单（图位先定死，再统一截图）

> 复盘方法①：**图位编号必须先定死再截图**——顺序反过来说明文档错漏百出。
> 这里的图号就是最终报告 / 实践 md 里的引用号，全局唯一，不重排。

## 截图纪律（模板「操作结果要尽量截图」）

1. **只截终端窗口**，不截整屏照片——模板原话「这里是截图，不是照片！」
2. 每张图**首行必须带 PS1 学号水印**（`[20241422穆弈涵 \u@\h \W]`），截不到就重截
3. 一张图只放一个场景，不要多块命令顶出屏外（复盘坑④）
4. 保存 PNG，命名 `图NN-名称.png`，存放 `screenshots/`
5. 统一在**收尾时重跑截图**：随机数/K 值会与 md 文本不同，**以截图为准回填 md**
   （保证 md 里的输出和截图逐字对应，老师抽查对得上）

## 截图方法

VM 内按下 `PrtSc`（UKUI 截图工具）→ 框选终端窗口 → 保存 → 拷进共享目录：

```
cp ~/Pictures/图NN-名称.png /mnt/hgfs/lab1/screenshots/
```

若 PrtSc 没反应，换命令保存全屏：`import -window root /tmp/图01.png`（需 imagemagick）或截图工具改名歧义的先告诉我。
